## カウンター

識別子は `@Enadorry`。公開版と同じ3テーマ・6パラメータを維持した。トップを実際に表示し、画像を各幅1回取得した。再試験では外部画像通信を模擬した。

| 観測 | PC 1440px | スマホ幅390px |
| --- | --- | --- |
| 実サービスで選ばれたテーマ | `kasuterura-4` | `booru-jaypee` |
| 画像応答 | HTTP 200、自然寸法350×100 | HTTP 200、自然寸法539×176 |
| 表示 | 350×100、1要求 | 約337×110、1要求 |

画像はいずれも縦横比を保ち、両端が画面内に収まった。通信を模擬して乱数を3通りに固定する追加試験では、`booru-touhoulat`を含むすべてのテーマで、トップと各作品詳細は1ページ1要求、音アプリは0要求。作品切替・動きの停止で追加要求は発生しなかった。外部サービス内部の計数値の増分は未確認。
